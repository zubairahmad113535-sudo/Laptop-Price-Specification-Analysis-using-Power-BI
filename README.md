# 💻 Laptop Price & Specification Analysis using Power BI

## 📌 Project Overview

This project analyzes laptop prices and specifications using Power BI to understand how different laptop features, brands, processors, RAM, storage, and operating systems are related to laptop pricing.

The main goal of this project was to transform raw laptop specification data into an interactive dashboard that allows users to compare products and identify pricing patterns.

This project focuses on **data analysis, data visualization, and business insights** rather than machine learning.

---

## 🎯 Project Objective

The objective of this project is to:

- Analyze laptop prices across different companies and products.
- Compare laptop prices based on RAM and storage.
- Analyze the impact of CPU specifications on laptop prices.
- Understand the distribution of laptops by operating system.
- Compare different laptop models and specifications.
- Build an interactive Power BI dashboard for exploring the data.
- Generate meaningful insights that can support laptop purchasing and product comparison decisions.

---

## 💼 Business Problem

With many laptop brands and configurations available in the market, customers can find it difficult to compare laptops based on price and specifications.

The business questions addressed in this project are:

1. What is the average laptop price?
2. What are the minimum and maximum laptop prices?
3. Which laptop companies have higher average prices?
4. How does RAM relate to laptop price?
5. How does storage type and capacity relate to price?
6. Which CPU configurations have higher average prices?
7. Which operating systems are most common?
8. Which laptop products appear most frequently in the dataset?
9. How can users interactively compare laptop specifications and prices?

---

## 📊 Dataset

The dataset contains laptop specifications and pricing information.

### Main Columns

- `Company` – Laptop manufacturer/brand
- `Product` – Laptop model/product name
- `TypeName` – Type/category of laptop
- `Inches` – Screen size
- `ScreenResolution` – Screen resolution
- `Cpu` – Processor information
- `Ram` – RAM capacity
- `Memory` – Storage capacity/type
- `Gpu` – Graphics processor
- `OpSys` – Operating system
- `Weight` – Laptop weight
- `Price_euros` – Laptop price in euros

The dataset contains approximately **1,300 laptop records**.

# 🔍 Key Insights

Several useful patterns were identified from the analysis.

### 💰 1. Large Price Range

Laptop prices range from approximately **€174 to €6.10K**, showing a significant difference between entry-level and premium laptop configurations.

### 📊 2. Average Laptop Price

The average laptop price in the dataset is approximately **€1.12K**.

### 🧠 3. RAM and Price

Higher RAM configurations generally show higher average laptop prices.

This suggests that higher-memory configurations are more common in premium or higher-performance laptops.

### ⚙️ 4. CPU and Price

Higher-performance processor configurations tend to have higher average laptop prices compared with lower-tier processors.

### 💾 5. Storage and Price

Different storage configurations show noticeable differences in average price.

SSD-based configurations are generally associated with higher-priced laptops compared with many HDD configurations.

### 🏢 6. Brand Differences

Average prices vary considerably between laptop companies.

This indicates that brand positioning, specifications, and product categories can contribute to differences in laptop pricing.

### 💻 7. Operating System Distribution

The operating-system visualization shows that Windows represents a large portion of the laptops in the dataset, while other operating systems make up smaller portions.

# 💡 Business Recommendations

Based on the analysis:

### For Customers

Customers should compare laptops based on their actual requirements rather than choosing only by brand.

For example:

- Basic users may not need high RAM.
- Students can focus on value-for-money configurations.
- Professional users may benefit from higher RAM and better CPUs.
- Storage type should also be considered when comparing similarly priced laptops.

### For Laptop Sellers

Sellers can use similar analysis to:

- Identify popular configurations.
- Understand price segments.
- Compare competitors.
- Identify premium product categories.
- Optimize product positioning.

### For Product Managers

The analysis can help identify which combinations of:

- RAM
- CPU
- Storage
- Brand
- Product type

are associated with higher prices.
